The Empirical Process of Building Trust

  1. Cycle of trust
    1. Untrusted system → Untrusted solution
    2. Check expectations
    3. Check syntax and structure
    4. Verification process
  2. Accumulation of evidence (positive and negative)
  3. Trusted system → Trusted solution (→ 1.2-1.4)
  4. Comprehensible trusted solution → Useful solution
